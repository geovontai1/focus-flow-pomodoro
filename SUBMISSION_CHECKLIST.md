# ED2 100-Point Submission Checklist

## Before submission
- [ ] GitHub repository is public.
- [ ] Repository contains all project files.
- [ ] At least 5 meaningful commits are visible.
- [ ] Supabase tables are created.
- [ ] Registration works.
- [ ] Login works.
- [ ] Logout works.
- [ ] Task Add works.
- [ ] Task completion toggle works.
- [ ] Task Delete works.
- [ ] Timer Start works.
- [ ] Timer Pause works.
- [ ] Timer Reset works.
- [ ] Timer reaches 0 and saves a Pomodoro session.
- [ ] Refreshing the dashboard preserves database data.
- [ ] App is deployed publicly.
- [ ] Demo video is 3–5 minutes and uploaded to YouTube as Unlisted.
- [ ] README contains the deployed-app link.
- [ ] README contains the demo-video link.
- [ ] README contains setup instructions.
- [ ] Canvas submission contains the public GitHub repository link.

## Demo order
1. Open deployed app.
2. Register.
3. Log in.
4. Add a task.
5. Show task priority.
6. Start timer.
7. Pause and reset.
8. Use a short timer for the demo if needed.
9. Show completed session/history.
10. Toggle task complete.
11. Delete task.
12. Briefly explain app.py, templates/, and Supabase.
